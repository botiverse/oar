## Claude 2.1.288

The [official changelog](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md#21288)
describes headless stream-recovery and resume fixes, including transcript
loading and saving. The live resume case checks ordinary conversation
continuity; it does not reproduce every failure described in that release.

The isolated npm installation passed three live cases through OAR:

- Basic conversation completed with native payloads retained on every frame
  and nonzero reported usage.
- A Bash call retained its command, result marker and matching call id.
- A disposed session resumed with the same native id and recalled the
  earlier codeword.

Claude's simulated-provider behavior suite was 18/18 clean (16 passed,
two inapplicable skips), and its strict vendor suite passed all 12 applicable
cases. Assertions and snapshots were unchanged.

## Antigravity 1.3.0

The [ACP registry](https://github.com/agentclientprotocol/registry/blob/main/antigravity-acp/agent.json)
now lists 1.3.0, previously available from Google's downloads while the
registry still listed 1.2.1. Its official Linux x64 archive was installed
into an isolated directory, including `agy_acp_server.par` and its
`localharness_external` companion. OAR detected the server and launched it
using the registry's Linux argument, `--uid=`.

Both `basic` and `tool-detail` stopped while opening the session with
the native error **Authentication required**. No conversation or tool ran,
so these attempts do not establish 1.3.0 conversation compatibility.
Authenticated validation remains outstanding. Existing
[1.2.1 evidence and gaps](../../docs/runtimes/antigravity.md), including
cancel waiting for a running shell command, are not promoted to claims about
1.3.0.

## Release state and reproduction

At the start of this check, main and the v0.15.0 tag were both `9df2289`,
and npm reported 0.15.0 for both OAR and oar-cli. During the check,
[PR 89](https://github.com/botiverse/oar/pull/89) added account-usage window
identity and length, with [PR 90](https://github.com/botiverse/oar/pull/90)
handling its 0.15.1 release separately. This maintenance change records
evidence only and does not bump package versions.

```sh
pnpm tsx experiments/runtime-versions.ts
pnpm tsx experiments/live-contract.ts claude --model haiku --only basic,tool-detail,resume
CI=true OAR_TEST=claude-aimock pnpm vitest run sea-trial/vendor
CI=true OAR_TEST=claude-aimock pnpm sea-trial
pnpm tsx experiments/live-contract.ts antigravity --model gemini-3.8-flash-low --only basic,tool-detail
```

Select the exact installations with `OAR_CLAUDE_BIN`, `OAR_CODEX_BIN`,
`OAR_CURSOR_BIN`, `OAR_KIMI_BIN` and `OAR_ANTIGRAVITY_BIN`. Managed host
launchers were not replaced. Antigravity requires its own native login or
supported credentials before rerunning the last command.

Local reports and available voyage logs are under
`oar-trial-run/runtime-check-2026-10-03/`, with the initial and final version
inventories plus `claude-2.1.288/` and `antigravity-1.3.0/`. The latter has a
failure report but no voyage because session creation failed. Raw artifacts
are not committed.

The documentation commit gate passed: typecheck, lint, 530 unit tests
(31 inapplicable skips) and the mock behavior suite (18/18 clean).
