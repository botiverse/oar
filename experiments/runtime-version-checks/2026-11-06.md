## OpenCode 2.2.5: cold MCP resume after upstream closure

[Upstream #54794](https://github.com/anomalyco/opencode/issues/54794) closed
on November 5. Its maintainer reports a fix from 2.2.4 and an ACP HTTP control
against development code. That does not resolve the previously observed path
by itself, so the new [local-provider probe](../opencode-mcp-resume-local.ts)
checks both stdio and HTTP echo servers through OAR's native ACP adapter.

For each transport, the first process completes a seed turn with a 250 ms
scripted first-token delay, then actually calls echo. Each of three successive
fresh-process resumes supplies the same server configuration and immediately
requests a distinct echo call. **None of the six resumed calls reaches echo.**
The first model request includes the native catalog notice saying the tool
is no longer available. Every turn nevertheless reports completion.

A final smoke of the committed probe repeats one cold resume per transport
with the same result. An earlier unseeded creation control also failed before
the catalog was ready; it is retained as a startup timing observation, not a
passing new-session control. Thus the comparison is explicitly a warmed
initial process versus cold resumed processes. The provider forces an immediate
call; these samples do not establish all resume timings, root cause, or whether
the upstream development branch still fails. OAR adds no sleep, retry or
catalog filtering. No new upstream comment was posted.

## Repeating the checks

Use isolated installations and absolute `OAR_ANTIGRAVITY_BIN`,
`OAR_CLAUDE_BIN`, `OAR_KIMI_BIN`, `OAR_CODEBUDDY_BIN`, `OAR_QODER_BIN` and
`OAR_QWEN_BIN` selections. Run the matching behavior backend and full vendor
suite, for example:

```sh
CI=1 OAR_TEST_REQUIRE_AVAILABLE=1 pnpm tsx sea-trial/all.ts kimi-aimock
CI=1 OAR_TEST=kimi-aimock pnpm vitest run sea-trial/vendor --maxWorkers 2
pnpm tsx experiments/qoder-native/replay-catalog.ts /absolute/qodercli 1.1.84
OAR_OPENCODE_BIN=/absolute/opencode pnpm tsx experiments/opencode-mcp-resume-local.ts /tmp/mcp-resume.json 3
```

Kimi, Qoder and the MCP resume probe intentionally preserve their failing
observations. The MCP script returns nonzero on a missing echo, and writes
private raw sidecars separately. The [Qwen probes](../qwen-native/README.md),
[CodeBuddy reproductions](../codebuddy-native/2026-10-29/README.md) and
[Claude classifier comparison](../claude-permissions/2026-11-06.md) specify
their individual controls. Build OAR before its native login tests.
