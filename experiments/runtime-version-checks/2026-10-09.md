## Native regressions and live checks

The Claude and Codex vendor suites used the actual new executables with
local scripted model providers and temporary native homes. Their passing
cases include tool-denial filtering, MCP, images, service-tier readback,
effort and control behavior. The shared behavior suites also passed,
including steer, queued input, abort, disposal and resume. Claude had two
unchanged skips and Codex three; the reported 19-case suite totals include
those skips. No assertion, timeout or adapter was changed.

Codex's `basic`, `tool-detail` and `resume` live scenarios passed with
`gpt-6-luna`. The tool result retained its command and output, and resume
kept the native identity and model, began a new record sequence and recalled
the earlier marker. Grok passed the same three scenarios with its reported
default model `grok-4.7`.

Claude's initial `basic` live attempt at 10:23 UTC returned a native session
limit, HTTP 429, with a 10:30 UTC reset. OAR reported `rate_limited` and zero
tokens. After that advertised reset, all three live scenarios passed at
10:30 UTC with the `haiku` alias, reported as `claude-haiku-5-5`. The original
voyage and failed report are retained separately from the successful retry.

Grok 1.0.50 (`c58f321264ba`) also passed the existing
[`grok-prompt-options.ts`](../grok-prompt-options.ts) experiment without
login or model quota. A local provider captured the actual system message:
the native override still wins over rules, resume still ignores new rules
but honors an override, and OAR's combined replacement/append ordering is
unchanged. Append-only resume remains explicitly refused. The CLI help
still advertises the top-level tool-denial flag but no ACP session denial
option; this inspection does not establish new native tool-filter support,
so the existing refusal remains unchanged.

The [Codex 0.162.0 release notes](https://github.com/openai/codex/releases/tag/rust-v0.162.0)
include command-output consolidation, provider capability configuration
and app-server changes. OAR's existing `aggregatedOutput` reading passed
the native tool checks. The [Claude changelog](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)
lists headless MCP reconnect, tool restrictions and interrupt fixes. Passing
our scenarios does not verify every upstream fix or imply the same result
on untested operating systems.
