## Reproduction and repository validation

Run `pnpm install --frozen-lockfile`, `pnpm run build`, then
`pnpm tsx experiments/runtime-versions.ts`. Install the two exact versions
in separate prefixes and select them using `OAR_ANTIGRAVITY_BIN` and
`OAR_CLAUDE_BIN`. For each, set `CI=1`, `OAR_TEST_REQUIRE_AVAILABLE=1`,
`OAR_TEST_CONCURRENCY=2` and a separate `OAR_TRIAL_RUN_DIR`, then run:

```sh
pnpm tsx sea-trial/all.ts <runtime>-aimock
OAR_TEST=<runtime>-aimock pnpm vitest run sea-trial/vendor --maxWorkers 2
```

The two runtime groups ran concurrently. Claude's additional control is
`pnpm tsx experiments/claude-login-browser/probe.ts <binary> 2.1.325`.
No login state or host installation is changed by these isolated probes.

For the macOS control, use the official 1.5.9 ARM64 archive and SHA-512
digest recorded in the JSON, extract it into a separate directory, verify
its digest and `--version`, then set `OAR_ANTIGRAVITY_BIN` to that executable.
On the product/test base above, after installation and build, run once with
a fresh `OAR_TRIAL_RUN_DIR`:

```sh
CI=1 OAR_TEST=antigravity-aimock OAR_TEST_REQUIRE_AVAILABLE=1 \
  pnpm vitest run sea-trial/vendor/mcp-servers-acp.vendor.test.ts \
  -t "a server named like one of the user's runs as the session's" \
  --maxWorkers 1
```

On `57451214`, `CI=1 pnpm run check` passed typecheck, lint, 4,137 tests
and all 18 applicable mock behavior cases. `git diff --check` passed.
Product code, dependency and CI pins, existing test assertions and deadlines,
and sharing policy are unchanged.
