# Runtime version check: 2026-11-26

Antigravity 1.5.18 passed the scheduled Linux, macOS and Windows ACP suites
and became the accepted baseline. Pi 1.6.1 and Qwen 0.28.6 failed at the
candidate test steps on all three platforms. OAR subsequently updated those
tests. The freeze preceded both that change and Qwen 0.28.7.
[Selected evidence](2026-11-26.json), [candidate run](https://github.com/botiverse/oar/actions/runs/45768939956).

## Antigravity

Google published 1.5.18 at 05:52 UTC. The 06:32 UTC freeze selected that
version. Each platform passed 18 shared behavior cases, including steering
and resume. The vendor suites passed 21 tests on Linux, 21 on macOS and
18 on Windows. The Linux x64, macOS arm64, macOS x64 and Windows x64
updater manifests still matched OAR's pinned archive URLs and SHA-512 values
at the evening check. [Baseline PR](https://github.com/botiverse/oar/pull/1201),
[Linux](https://github.com/botiverse/oar/actions/runs/45768939956/job/139736702377),
[macOS](https://github.com/botiverse/oar/actions/runs/45768939956/job/139736702347),
[Windows](https://github.com/botiverse/oar/actions/runs/45768939956/job/139736702486).

The upstream release rejects corrupt images, resolves file URI paths before
permission checks, and fixes Windows plugin loading across drives. OAR
0.137.0 disables background auto-update by default for non-update Antigravity
processes. Reading quota through print mode requires explicit opt-in.
Stable Linux and macOS installs from 1.5.10 can read skills from files.
[Upstream release](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.18),
[update suppression](https://github.com/botiverse/oar/pull/1202),
[read options](https://github.com/botiverse/oar/pull/1207).
