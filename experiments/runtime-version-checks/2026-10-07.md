## Claude Code

Claude 2.1.292 passed `basic`, `tool-detail` and `resume` on `haiku`.
The resumed native session kept its identity and recalled the earlier
transcript. All 14 applicable vendor tests passed against the real binary
and a scripted provider, without snapshot changes. The simulated-provider
behavior suite was 19/19 clean, with only capability-based skips.

The [official changelog](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)
changes the default stdio MCP protocol negotiation and fixes print-mode
background work ending prematurely. The MCP vendor tests exercised real
stdio and HTTP echo servers, credential delivery, tool results, reattachment
on resume, coexistence with user-configured servers and absence of
credentials in recorded frames. These passing tests do not establish
compatibility with every MCP server or verify scheduled background work.

## OpenCode

OpenCode 1.18.35 passed the native
[`opencode-prompt-options.ts`](../opencode-prompt-options.ts) probe against a
local provider: replacement targets the active agent, appended instructions
preserve order, resume uses the saved agent, literal interpolation markers
remain literal, and model selection, denied tools and native configuration
survive. Removed-agent and inline-configuration conflicts still reject, and
temporary instruction files are removed.

All three applicable MCP vendor tests passed with the real binary and a
scripted provider. Stdio and HTTP tools execute with their credentials,
resume reattaches only explicitly supplied servers, a same-name session
server overrides the user's server while other user servers remain, and
prompt replacement/append work together with both MCP transports. No
credential marker leaked into the recorded session frames.

All 13 live scenarios passed on the free `opencode/big-pickle` model,
including multiple turns, tool details, busy and late controls, steer,
queue, abort, disposal mid-turn, cursor replay, native-id resume,
subagent attribution, unexpected process death and unknown-model rejection.
No retries, adapter changes, timeout changes or assertion changes were
needed.

The [1.18.35 release notes](https://github.com/anomalyco/opencode/releases/tag/v1.18.35)
include xAI tool-result image handling. Today's probes do not verify that
provider-specific image fix, authenticated providers or the separate
OpenCode HTTP server API.

## Reproduction and release scope

At the start, main, `v0.33.1` and both npm packages agreed on 0.33.1.
The SDK versions and dependency manifests did not change. The local commit
gate passed on the probe baseline (779 tests and the mock behavior suite).
This change is compatibility documentation only and does not need a new npm
release. Only the two updated native binaries received new live calls;
unchanged versions were
inventoried without repeating their compatibility claims.

Before the report was committed, the separate logout change had shipped as
0.34.0. Both npm packages were verified at that version, and the report was
rebased onto `74993c2`. The live evidence above remains from `e1f9177`;
it does not claim to retest logout. The final full check passed after the
rebase: 797 tests and the 19-case mock behavior suite.

```sh
pnpm tsx experiments/runtime-versions.ts
pnpm tsx experiments/live-contract.ts claude --only basic,tool-detail,resume
pnpm tsx experiments/live-contract.ts opencode
pnpm tsx experiments/opencode-prompt-options.ts
CI=true OAR_TEST=claude-aimock pnpm vitest run sea-trial/vendor
OAR_TEST=claude-aimock pnpm sea-trial
CI=true OAR_TEST=opencode-aimock pnpm vitest run sea-trial/vendor/mcp-servers-acp.vendor.test.ts
pnpm run check
```

Set `OAR_CLAUDE_BIN` and `OAR_OPENCODE_BIN` to the isolated native
installations. The other inventory overrides select Antigravity 1.3.0,
Codex 0.160.1 and Kimi 2.1.1; Pi and Cursor are resolved from their actual
SDK importers. No managed executable was replaced.
