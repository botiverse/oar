# Runtime version check: 2026-11-27

Pi 1.6.1 and Qwen 0.28.7 became the accepted CI versions after all ten Pi jobs
and all three Qwen jobs passed across Linux, macOS and Windows. Pi 1.7.0 was
published after the 06:33 UTC freeze. Antigravity stayed at 1.5.18.
[Candidate run](https://github.com/botiverse/oar/actions/runs/45952571971),
[Pi update](https://github.com/botiverse/oar/pull/1218),
[Qwen update](https://github.com/botiverse/oar/pull/1217), [selected evidence](2026-11-27.json).

## Antigravity

The latest official release and all four updater manifests reported 1.5.18.
The Linux x64, macOS arm64, macOS x64 and Windows x64 archive URLs and SHA-512
values matched the accepted pin. The candidate workflow omitted the unchanged
version. Its most recent three-platform ACP pass was on November 26.
OAR 0.139.0 now recognizes whitespace-padded frontmatter delimiters in
`SKILL.md` as the native CLI does. On Linux the file reader and the native skills command
returned the same names and descriptions for both padded-fence fixtures in
three comparison rounds, with zero model requests.
[Official release](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.18),
[previous ACP run](https://github.com/botiverse/oar/actions/runs/45768939956),
[reader fix](https://github.com/botiverse/oar/pull/1221).
