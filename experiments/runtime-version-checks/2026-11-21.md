## Antigravity skill discovery

Version 1.5.14 installed a built-in skill at
`builtin/skills/conversations/SKILL.md`. Both Linux skill tests treated
any path containing a `conversations/` segment as saved history. A
four-case comparison inspected the actual history directory and SQLite
summary table after a configured query and a signed-out query on each
version. All four cases left the history directory empty, had zero summary
rows and made zero model requests. Only 1.5.14 installed the skill. The
fixture should check the native history directory directly. Until then,
its two path assertions fail on this candidate.
[Original skill fixture](../../sea-trial/vendor/antigravity-skills.vendor.test.ts),
[comparison by version and account mode](2026-11-21.json).

## Qwen native behavior

On 0.28.3 a new and a resumed session returned the expected scripted
tool result. The repeated-paragraph fixture kept the repeated text, with
thinking and text emitted in separate assistant frames. The interrupted
turn returned a native error and a subsequent prompt completed in each
of the three direct scenarios. OAR already covers all 14 provider preset
credential names and four distinct native preflight names found in the
published package. [Direct protocol probe](../qwen-native/probe.ts),
[per-scenario results](2026-11-21.json).

A warm session acknowledged initialization in 1,641 ms with the extension
lock held. Its first prompt produced zero provider requests while the lock
remained held and completed after release. A subsequent ordinary prompt
completed with the lock held again. Initialization alone does not establish
first-prompt readiness. [Lock probe](../qwen-native/lock-lifetime.ts).
