## Repeating the checks

Install the exact versions above into isolated prefixes. Set `OAR_CODEX_BIN`,
`OAR_KIMI_BIN`, `OAR_QODER_BIN`, `OAR_ANTIGRAVITY_BIN` and `OAR_AGY_BIN` to
the corresponding executables. The last two refer to the same standalone
Antigravity binary. Use a fresh `OAR_TRIAL_RUN_DIR` for each backend and at
most two groups concurrently.

```sh
pnpm install --frozen-lockfile
pnpm run build
pnpm tsx experiments/runtime-versions.ts
# Repeat for codex-aimock, antigravity-aimock, kimi-aimock and qoder-native:

CI=1 pnpm run check
```

native execution evidence is Linux-only. Product code, dependency versions,
