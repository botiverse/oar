experimental subagent packages. A version match does not prove compatibility.

## Qoder 1.1.83: real DeepSeek BYOK execution

This follow-up supplements the native replay and model-catalog investigation.
It is a targeted execution sample, not a new complete version inventory.

Bugen ran the [bounded probe](../qoder-deepseek/README.md) on Linux x64 using
OAR `4fd225c8`, Qoder 1.1.83, an existing Qoder Free login and a DeepSeek
pay-as-you-go API key. The native BYOK catalog offered DeepSeek-Flash, and
credential validation succeeded. Across three submissions:

- Text inference returned the requested marker.
- Native Read and Write tools ran once each; the resulting file matched.
- A fresh native process resumed the saved session and recalled its marker.

The two first-process completions and the resumed completion were native
`result` / `success` records with `isError: false`. Reported usage was
128,104 input / 254 output / 54,272 cache-read tokens for the first process,
and 37,275 / 24 / 18,560 for the resumed process. The temporary BYOK
configuration was removed, and the control process exited with code zero.
The probe was not rerun to collect these results.

This is execution evidence for these three flows on 1.1.83 after the replay
regression in 1.1.82. It does not verify cancellation, first-party model
entitlements, subscription quota or rate limits. It does not restore native
replay or replace the full required suite: CI stays pinned to 1.1.81 with
unchanged assertions and deadlines. The real-key probe remains manual.

Source: Bugen's November 5 result, Raft message

from the locally reproduced read-only catalog and validation controls.

## Codex 0.166.0: publish the native terminal cleanup evidence

The [twelve-case native probe](../codex-background-terminals/README.md), its
rerunnable script and selected observations are now in the repository.
These are the November 5 observations reviewed for PR #633, not a new run.
A successful native `terminate` or `clean` response and an empty terminal
list did not imply that detached descendants had exited. `clean` also
reached earlier commands in the same thread; a command in its launch window
was not yet listed. The report records process identities and probe cleanup.

The implemented opt-in process-table cleanup and its limits remain in the
[Codex runtime page](../../docs/runtimes/codex.md#ending-a-turns-processes-on-abort).
This evidence publication changes no product cleanup behavior or CI assertion.
