## Pi upgrade and compatibility

The bundled coding-agent SDK and pi-ai dependency now use **0.99.2**, with
the workspace development dependency pinned to the same version. Pi's
[release notes](https://github.com/earendil-works/pi/releases/tag/v0.99.2)
describe MCP discovery/authentication changes and fixes to provider model
selection, prompt submission, codemode and provider requests. This update
keeps OAR's existing adapter and public surface.

The full applicable live battery passed: basic, multi-turn, tool detail,
busy/late control, steer, queue, abort, mid-turn dispose, cursor replay,
resume and bad-model rejection. Steer landed in the same turn; queued input
ran as a spontaneous next turn. Abort and mid-turn dispose carried the
runtime's aborted outcome. Resume retained the native session ID, recalled
the marker and restarted the stream at sequence zero. Subagents and process
killing remain inapplicable.

Strict simulated-provider vendor suites passed for Pi (8 cases), Claude
(12) and Codex (10). Pi's simulated-provider behavior suite was 18/18 clean,
including its inapplicable skips. No adapter or test change was needed.
