4 · Agent status bar — strict projection of the status fold

The bar renders (AgentStatus, stallOf(status, now, 15s)) and NOTHING else — a pure function of the fold plus its one clock overlay. Every UI state below is one of those values; there is no third input and no invented state.
thinking · turn t-04 · 0:41 · 12 events · 1 queued claude · haiku · a7f2c9e1
thinking · silent 24s claude · haiku · a7f2c9e1
idle · last turn failed · API Error: 400 max_tokens exceeds model limit claude · haiku · a7f2c9e1
Layer 1 · the ontology — one lamp state per AgentStatus value, total
idle
kind: "idle" · 5s faint
waiting model
phase: "waiting_model" · 2.2s
thinking
phase: "thinking" · 1.6s
responding
phase: "responding" · 0.9s
tool · bash
phase: {tool, callId} · sky 1.2s
Layer 2 · the overlay — fold × clock, presentation-only

stallOf(status, now, 15s) ≠ null recolors the lamp amber (2.4s) and appends "· silent Ns" after the UNCHANGED phase word. Stall never replaces the ontology word — the fold still says thinking; the clock says nothing has arrived. The next event updates lastEventAt and the overlay vanishes by construction.

Not a status — turn outcomes

turn_ended folds to idle{lastTurnOutcome}. The agent is ALIVE and idle after a failed turn, so there is no dead lamp and no rose lamp state — outcomes render as the idle bar's dim annotation (last turn failed · reason / completed / aborted) and as quiet markers in the conversation flow. Coloring the lamp by outcome would smuggle history into a presence indicator.

The transition table the bar inherits (verbatim from observe/agent-status.ts)
turn_started      → running/waiting_model
thinking_delta    → running/thinking
text_delta        → running/responding
tool_call_started → running/{tool, callId}
tool_call_ended   → running/waiting_model   (the model consumes the result next)
turn_ended        → idle{lastTurnOutcome}

Type: Inter / ui-monospace · Surface: near-black greens (ink scale) · Accent: single green (oar-500 #34d399), amber reserved for stall/steer, sky for tool activity, rose for failure. No gradients, no glass, 1px white/5 hairlines.
