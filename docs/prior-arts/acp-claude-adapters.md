Research date 2026-10-06, read only. Purpose: input for `oar acp claude` (an ACP bridge over OAR's claude runtime, which drives `claude -p --input-format stream-json --output-format stream-json`).

The Lody adapter is a **fork of the official adapter**: same file layout, and `docs/UPSTREAM_SYNC.md` records a merge of upstream main at `bdb50ad` (upstream 0.84.0) on 2026-09-29. So it shares about 95% of its code with the official adapter and lags it by upstream 0.85.0, 0.85.1 and 0.86.0. The Lody-specific parts are additive (`_lody/*` methods, `_meta.lody`, usage accounting, rate limits).

Citation convention: `A:` = `claude-agent-acp/src/`, `L:` = `lody/packages/acp-extension-claude/src/`, `C:` = `lody/packages/acp-extension-core/src/`. A bare `file:line` inside a section is relative to that section's adapter `src/`.

ACP schema reference points (`agent-client-protocol/schema/v1`): stable agent methods include `session/list`, `session/delete`, `session/resume`, `session/close`, `logout` (`meta.json`); `session/fork` and `providers/*` are unstable only (`meta.unstable.json`). Stable `SessionUpdate` kinds: `user_message_chunk, agent_message_chunk, agent_thought_chunk, tool_call, tool_call_update, plan, available_commands_update, current_mode_update, config_option_update, session_info_update, usage_update`. Unstable adds `plan_update, plan_removed, notice, compaction_update, compaction_summary_chunk, subagent_update, session_message, session_message_chunk` (`schema.unstable.json`). Note the unstable schema names `subagent_update`, while both adapters emit draft `subagent_spawned` / `subagent_state_update`.

## Differences that matter

1. **One codebase, two release lines.** Lody is the official adapter plus additive `_lody` contracts, frozen at upstream 0.84.0 (`L:docs/UPSTREAM_SYNC.md`). Treat the official adapter as the behavioral reference, and Lody as the list of extras a demanding client asked for: acknowledged steer, per-turn ids, fork at turn, accounting-grade usage, rate limits, subagent event stream.
2. **Both drive Claude through the Agent SDK `query()`, not bare `claude -p`.** `query()` spawns the native CLI and adds a control channel the adapters depend on: `canUseTool` (all approvals), hook callbacks (final diffs, model sync, compaction summary, task plans), `interrupt`, `setModel`, `setPermissionMode`, `applyFlagSettings` (effort, fast mode, agent), `supportedCommands`, `stopTask`, `getContextUsage` (`A:acp-agent.ts:9469-9637`). Inference for OAR: a bridge over OAR's stream-json CLI runtime must reproduce those control requests itself, or it loses permission prompts, live model/effort switches and clean interrupt.
3. **Neither uses ACP `fs/*` or `terminal/*`.** Claude's tools run on the agent host; diffs come from tool input and the PostToolUse hook; terminal output rides a `_meta` display extension (`terminal_output`), gated on a client `_meta` flag (`A:tool-calls/renderer.ts:176-180, 306-345`; `A:CHANGELOG.md:1021`).
4. **Second prompt is queued, not rejected, in both.** Steering is only via extensions: official `_session/steering` (idle falls back to a detached new turn or `promptRequired`); Lody adds `_lody/session/steer` with a refusal contract (`-32600`) and a `steer_applied` boundary notification.
5. **Subagents**: plain clients get flattened child tool calls tagged `_meta.claudeCode.parentToolUseId`. Official's structured path is the draft ACP `subagent_spawned` / `subagent_state_update` child sessions (not the unstable schema's `subagent_update`); Lody's is the root-scoped `_lody/subagents/event` stream that keeps child output out of the parent transcript.
6. **Usage**: official reports context window occupancy, session-cumulative cost and token totals. Lody adds per-result per-model increments with thinking split out and resume baselines, plus subscription rate limits read via an undocumented OAuth endpoint and direct credential-store reads (`L:usage.ts:321-371, 484-489`).
7. **Fork**: official `session/fork` returns only a new id (SDK `forkSession`). Lody's `_meta.lody.forkAtTurn` returns a live session resumed at a published turn uuid.
8. **Lody misses upstream 0.85/0.86 fixes**: cancel no longer leaves queued prompts in Claude Code's queue, close ends turns before answering, `/mcp` in chat, agent persona picker, concurrent load replay, SDK 0.3.286/0.3.287 adaptations (`A:CHANGELOG.md:3-45`).
9. **Shared gaps** relevant to OAR's design: no audio or blob resources, no mid-session thinking budget, `dontAsk` never advertised, no `models`/`set_model` (model only as a config option), many updates gated on AIR or draft capabilities that generic clients will not declare.
